Файл: MaxByEliminationBad.java
Ошибка в строке: 8
Суть ошибки: Неправильная инициализация переменной y - должно быть y = a.length-1, но используется y = a.length.

Последствия:
1) При первом сравнении a[x] <= a[y] произойдет выход за границы массива (ArrayIndexOutOfBoundsException).
2) Нарушается инвариант цикла (loop_invariant 0 <= x <= y < a.length), так как y изначально равен a.length, что недопустимо.

Пример некорректной работы:
max(new int[]{3, 1, 2}) → выбросит исключение вместо возврата индекса максимума (0).

Исправленная версия:
См. корректный код в MaxByElimination.java (строка 8: y = a.length-1).


Файл: SumMax.java  
Ошибка в строке: 6  
Суть ошибки: Неправильная инициализация max - должно быть max = Integer.MIN_VALUE, но используется max = a[0].  

Последствия:  
1) Если массив a пуст (нарушает @requires), метод выбросит ArrayIndexOutOfBoundsException при попытке доступа к a[0].  
2) Хотя контракт @requires гарантирует непустой массив, инициализация max = a[0] избыточна, так как цикл и так проверит все элементы.  

Пример некорректной работы:  
m(new int[]{-5, -3, -10}) → отработает корректно, но если бы массив мог быть пустым, возникло бы исключение.  

Исправленная версия:  
Лучше явно указать max = Integer.MIN_VALUE перед циклом, чтобы логика поиска максимума была универсальной

Файл: SelectionSort.java
Ошибка в строке: 4 (контракт ensures)
Суть ошибки: Неверное условие сортировки в постусловии - должно быть arr[k] <= arr[k+1] (сортировка по возрастанию), но указано arr[k] >= arr[k+1] (сортировка по убыванию).

Последствия:
1) Реализация сортирует по убыванию, но спецификация утверждает сортировку по возрастанию, что приводит к противоречию.
2) Средства формальной верификации (например, OpenJML) будут показывать ошибки при проверке соответствия кода спецификации.
3) Путаница в документации - пользователь класса будет ожидать поведения, противоположного реальному.

Пример некорректной работы:
sort(new int[]{3, 1, 4, 2}) → результат [4, 3, 2, 1], но постусловие ожидает [1, 2, 3, 4].

Исправленная версия:
Необходимо либо:
1) Изменить постусловие на arr[k] >= arr[k+1], если требуется сортировка по убыванию
2) Либо изменить реализацию на сортировку по возрастанию
