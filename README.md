Файл: MaxBad.java
Ошибка в строке: 7
Суть ошибки: неправильное сравнение в тернарном операторе – вместо t > k ? t : k используется t > k ? i : k.

Последствия:
1) Метод может вернуть i, даже если i не является максимумом (например, если j > i, но i > k).
2) Нарушается спецификация JML (условие ensures \result == i  \result == j  \result == k), так как результат может не соответствовать ни одному из аргументов.

Пример некорректной работы: max(1, 3, 2) → вернет 1 (ожидалось 3).

Исправленная версия: См. корректный код в Max.java (строка 6: return t > k ? t : k).


Файл: MaxByEliminationBad.java
Ошибка в строке: 8
Суть ошибки: Неправильная инициализация переменной y - должно быть y = a.length-1, но используется y = a.length.

Последствия:
1) При первом сравнении a[x] <= a[y] произойдет выход за границы массива (ArrayIndexOutOfBoundsException).
2) Нарушается инвариант цикла (loop_invariant 0 <= x <= y < a.length), так как y изначально равен a.length, что недопустимо.

Пример некорректной работы:
max(new int[]{3, 1, 2}) → выбросит исключение вместо возврата индекса максимума (0).

Исправленная версия:
См. корректный код в MaxByElimination.java (строка 8: y = a.length-1).
